# apexpad

Source of **[apexpad.io](https://apexpad.io)**, the home page of ApexPad: a fair-launch memecoin factory where 100 % of the supply goes into locked liquidity.

Static site (HTML, CSS, vanilla JS), served by GitHub Pages behind Cloudflare. No build step.
